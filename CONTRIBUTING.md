# Contributing to CloudForge

Thank you for your interest in contributing to CloudForge!

## Code of Conduct

Please be respectful, professional, and collaborative in all communication and code reviews.

## Getting Started

1. **Fork the Repository**: Create a personal fork on GitHub.
2. **Clone Locally**: 
   ```bash
   git clone https://github.com/maheshMadiwalar18/cloudeForge.git
   ```
3. **Run Locally**:
   - For backend development details, refer to `backend/README.md`.
   - For frontend Next.js development details, refer to `frontend/README.md`.

## Development Workflow

1. Create a new branch: `git checkout -b feature/my-new-feature`
2. Make your changes.
3. Write unit tests for new logic (under `backend/tests` or frontend test suite).
4. Run tests and linting:
   - Backend: `pytest backend/tests/` and `flake8 backend`
5. Commit with a clear, descriptive message.
6. Push to your branch and open a Pull Request.

## Pull Request Guidelines

- Ensure unit tests pass.
- Follow existing code formatting conventions.
- Do not commit any real credentials, API tokens, or secrets.
