# Security Policy

## Supported Versions

Only the latest release of CloudForge is supported for security updates.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅ Yes    |
| < 1.0   | ❌ No     |

## Reporting a Vulnerability

We take security seriously. If you find a security vulnerability, please do **not** open a public GitHub issue. Instead, report it directly by emailing us at **security@cloudforge.example.com**.

Please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.

We will acknowledge receipt of your report within 48 hours and provide a timeline for resolution.
